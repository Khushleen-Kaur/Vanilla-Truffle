### A Tiny Dragon. A Giant Appetite for Magic.

## 📜 The Story Behind the Magic

It all began in a nineteenth-century kitchen.

Odin, a chef experimenting with a recipe from an old cookbook, was mixing mysterious ingredients when suddenly—

**BOOM! 💥**

Chocolate splashed everywhere, magical ingredients filled the air, and a tiny purple dragon appeared inside the truffle mixture, wearing a chef hat and looking ready to take over the kitchen.

And just like that, Vanilla Truffle was born.

Now, he spends his days inventing magical recipes, experimenting with unusual ingredients, and turning everyday cooking into extraordinary adventures.

The website brings his journey to life through an illustrated, seven-chapter storybook experience, along with a bonus adventure: **“Vanilla and the Butterfly.”**

## 🍪 Magical Recipe Projects

Vanilla's portfolio showcases four signature culinary creations, each with its own personality, magical effect, and interactive Taste Test experience.

### 1. 🗣️ Bak Bak Bun — Talk Talk Truffle

A mischievous bun that temporarily steals the voice of anyone who bites it until every crumb is gone.

*Warning: Your next conversation might have to wait!*

### 2. 🧠 Never Forget Biscuits

A mysterious biscuit with a rather confusing side effect: temporary memory lapses.

*“Wait… why did I come into this kitchen?”*

### 3. 🎵 Crazy Cracking Cookies

Cookies that make anyone who eats them speak in delightfully nonsensical rhymes.

*Why speak normally when everything can rhyme?*

### 4. 😴 Active Marshmallow

A soft, magical marshmallow that sends its eater into a sweet, peaceful sleep.

*One bite, and the world becomes a little dreamier.*

Each creation contributes to Vanilla's fictional culinary universe, combining imaginative storytelling with playful interactions.

## ✨ Features

### 🎬 1. Cinematic Spotlight Introduction

The adventure begins in a darkened room, where a warm spotlight reveals Vanilla Truffle with his introductory greeting.

Visitors can watch the reveal or skip straight to the kitchen. Returning visitors receive a friendly welcome back.

### 🎨 2. Interactive Character Profile

Discover Vanilla's appearance, personality, profession, and signature quirks through a visually rich character introduction and an illustrated character sheet.

### 📚 3. Illustrated Origin Story

Explore Vanilla's origin through a horizontally navigable, seven-chapter storybook featuring custom illustrations and scene-based storytelling.

A bonus butterfly adventure adds another delightful discovery to his world.

### 🧁 4. Custom Cupcake Cursor

Desktop visitors can enjoy a playful cupcake-and-cherry cursor accompanied by falling candy particles.

The effect automatically adapts to touch-oriented devices and respects reduced-motion preferences.

### 👀 5. A Dragon That Reacts to You

Vanilla isn't just an illustration!

- His head and eyes subtly follow the visitor's pointer.
- Clicking him triggers a playful speech bubble, surprised expression, and dragon squeak.
- His mood system features Happy, Sleepy, Mischievous, and Surprised states.

### 🔊 6. Magical Sound Design

The kitchen comes alive with bubbling cauldrons, crunchy bites, sparkling chimes, dragon-fire effects, and celebratory sounds.

A global mute toggle lets visitors control the sound experience.

### 🌗 7. Light and Dark Kitchen Themes

Choose between two magical atmospheres:

- **Light Mode:** Soft lavender, lilac, and creamy vanilla tones.
- **Dark Mode:** Midnight purple, deep violet, and glowing lavender accents.

Theme preferences persist between visits.

### 🧪 8. Interactive Cooking Mini-Game (Kitchen Lab)

Enter the kitchen, select ingredients, experiment with combinations, and discover what comes out of the cauldron.

The results range from delicious desserts to completely unexpected culinary disasters.

### 💬 9. Dragon Chat

Interact with Vanilla through a playful, character-themed dialogue experience that brings his mischievous personality to life.

### 📜 10. Cookbook Guestbook

Leave a little love in Vanilla's cookbook! Visitors can write messages that appear as handwritten-style notes, with input validation and character limits.

Guestbook entries are stored locally in the browser.

## 🧑‍🍳 Interactive Cooking Game

**The kitchen is yours. What will you create?**

Choose from eight ingredients:

- 🍫 Chocolate
- 🍓 Strawberry
- 🥛 Cream
- 🍪 Chocolate Chips
- 🌶️ Pepper
- 🌼 Vanilla
- 🍬 Sugar
- ☁️ Marshmallow

Add ingredients to the bubbling cauldron, remove them, and experiment with different combinations.

### Sample magical recipes

| Ingredients | Result |
|---|---|
| Strawberry + Cream | Strawberry Cream Cake |
| Chocolate + Cream + Chocolate Chips | Triple Chocolate Truffle |
| Vanilla + Strawberry + Cream | Vanilla Strawberry Dream Cake |
| Pepper + Sweet Ingredients | Dragon-Flame Disaster! 🔥 |

The cooking game includes animated reactions, playful dialogue, and surprising outcomes for unfamiliar combinations.

Because in Vanilla's kitchen, experimentation is encouraged. The fire extinguisher is optional… probably.

## 🔎 Hidden Easter Eggs

Curiosity is rewarded in Vanilla's kitchen. Some surprises are waiting for visitors who explore beyond the obvious.

### ☁️ The Secret Active Marshmallow

Look carefully around the kitchen and investigate the refrigerator/freezer. Discovering the hidden marshmallow unlocks a golden trophy badge in the navigation bar.

The discovery persists between visits.

### 🍪 The Never Forget Biscuit

A secret biscuit is tucked away near the cookbook counter. Find it and take four progressive bites, complete with crunchy sound effects and a special celebratory message.

These hidden interactions turn the website into a small exploration game, encouraging visitors to click, experiment, and discover.

**Psst… the best discoveries aren't always on the menu.** 👀

The visual identity combines pastel-purple fantasy, whimsical food illustrations, elegant typography, and playful animations.

The design uses a consistent character style and a carefully selected palette to make the experience feel like an illustrated magical cookbook.

## 📱 Responsive Design and Accessibility

Magic should work on every screen!

The website incorporates:

- Responsive layouts for desktop, tablet, and mobile devices.
- Touch-friendly interactions for smaller screens.
- Adaptive character diagrams and story sections.
- Automatic disabling of custom cursor effects on touch-oriented devices.
- Light and dark themes.
- A global sound mute control.
- A skip option for the cinematic introduction.
- Reduced-motion support for the custom cursor effect.
- Input validation and character limits for the guestbook.

The aim is to make the experience engaging while keeping navigation and interactions comfortable across devices.

## 🚀 Getting Started

Want to explore the code or run the project locally? Follow these steps.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) — a compatible version for your installed Vite setup.
- npm, which is included with Node.js.
- Git, if you want to clone the repository.

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

Replace the placeholder with your actual GitHub repository URL.

**2. Navigate to the project directory**

```bash
cd Vanilla-Truffle
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Visit the URL printed in your terminal, usually:

```text
http://localhost:5173
```

### Build for production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
